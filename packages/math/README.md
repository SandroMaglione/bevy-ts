# `@typeonce/bevy-ts-math`

Validated math values for bevy-ts games: `Scalar`, `Vector2`, `Size2`, `Aabb`, and `InputAxis`. Every module exports constructors that validate untrusted input, so they work as `Descriptor.ConstructedComponent(...)` constructors and survive snapshot restore.

```sh
pnpm add @typeonce/bevy-ts-math @typeonce/bevy-ts
```

Released together with [`@typeonce/bevy-ts`](https://www.npmjs.com/package/@typeonce/bevy-ts), always with the same version.
